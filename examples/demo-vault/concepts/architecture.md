# Architecture

[[Nova]] is a fictional assistant with three layers: Markdown ingestion, graph retrieval, and optional local response generation. Embeddings select semantic seeds; wikilinks connect related notes; BM25 adds lexical evidence.

[[retrieval]] describes the read path. Learning is a separate, explicit action in this demo; disabled neurogenesis means no new concept notes.
